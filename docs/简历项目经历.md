# 可直接用于简历的项目经历

**多跳问答 Agent 与小模型后训练实验**

技术栈：Python、ReAct、Qwen、Transformers、PEFT、TRL

- **Agent 实现：**在原有 ReAct 智能体上完善 Wikipedia 检索与 Python 数学工具调用，支持模型输出解析、滑动窗口上下文、结构化错误反馈和有限纠错。
- **评测设计：**将标准答案与推理执行隔离，使用答案级 EM/F1；针对重复采样与成功轨迹筛选的混杂，设计固定预算的 ReAct、错误反馈和独立重采样对照，全量记录尝试，区分实际选择结果与 oracle 覆盖率。
- **数据构建：**从按正确性筛选的历史问答记录构建答案级 SFT 样本与规则偏好对，按问题哈希划分训练/验证/测试，保存数据来源与校验值；支持从新版日志导出精确上下文的 Agent 决策训练样本。
- **后训练实践：**在 RTX 4060 Laptop 8GB 上完成 Qwen2.5-0.5B 的小规模 LoRA SFT→DPO 流程验证，保存适配器与训练记录，并对基座、SFT、DPO 模型进行同题直接回答评测。
- **工程验证：**采用 Git 分阶段管理改动，补充 25 项离线回归测试与端到端演示，覆盖答案泄漏、预算约束、工具异常、判分与数据划分。

## 面试需要掌握的真实规模
- 答案级 SFT：49 条训练、6 条验证、7 条测试；实际训练 20 步。
- 规则偏好 DPO：15 对训练、0 对验证、2 对测试；实际训练 5 步。
- 本地测试：同一 10 题、确定性解码，基座 EM 30%，SFT 和 DPO 均 20%，未观察到提升。
- 历史 200 题记录只做离线重评分，不能冒充本次模型改进效果。
- Agent 决策训练数据导出已实现；本轮实际训练使用的是答案级数据，不声称完成工具策略训练。
