## 固定设计

- 一题 × 一种子 × 一模式只有一条轨迹，不因不正确而重新生成。重复种子全部汇总，不取 best-of-N。
- OFF 和 ON 都能在错误后继续，调用、token、上下文窗口预算完全一致。唯一干预是错误后的显式纠错指导语。
- 这是 observable-error feedback / self-repair 消融，不是依赖答案正确性的语义反思，也不是 Reflexion 论文复现。
- 所有模型请求（包括格式错误）消耗调用预算。API 不做隐式重试；网络故障在分母中。
- 每题对应的两种模式次序和整体任务调度预先随机化。并行是样本级线程，不改变单轨迹顺序。
- 开发集 45 题（QA 34 / Math 11）；复测集 215 题（QA 166 / Math 49）。划分依据标准化题目的 SHA256，不依据答案或正确率。
- 种子 11、29、47；每任务每模式 3 次重复，主指标是单轨迹通过率均值。seed 参数不保证服务商复现。
- 所有原始题目曾用于历史开发；本次 test 只是冻结操作划分，不宣称训练数据去污染或全新盲测。
- Prompt、工具和指标在 dev smoke 后冻结；完整复测结束前不根据 test 表现改策略。
- 预注册 manifest 包含样本、数据哈希、代码版本、配置。started.jsonl 在推理前落盘，episodes.jsonl 在完成后逐条 fsync。
- 中断后 resume 保留已完成项；已开始却无结果的项记 interrupted failure，禁止重新采样。正在运行时不要启动第二个写入进程。
- 跨版本、不同 CLI 设置或数据哈希不能恢复同一实验。

## 判分和统计

QA 使用标准化的答案 exact match 与 token F1；yes/no/noanswer 特殊答案必须严格匹配，参照 [HotpotQA 官方评测器](https://github.com/hotpotqa/hotpot/blob/master/hotpot_evaluate_v1.py)。检索方式是实时 Wikipedia，不包含官方 distractor context/supporting facts，不能对标官方完整 benchmark。

数学只解析整段最终表达式；受限 AST 解释器支持数值、分数、根号、幂、阶乘，禁止 eval。rel_tol=1e-6、abs_tol=1e-8。一般符号、多元解、单位与复杂 LaTeX 不支持；不能解析时仅允许表达式严格一致。这是保守判分器，不声称覆盖全部数学等价性。

每种子报告 Wilson 区间；ON−OFF 的主要区间按题目聚类 bootstrap，保留同一题全部种子，避免把重复采样当作新题。报告改正数/退化数、调用/token/延迟、格式错误、工具错误、预算耗尽。小数据集上的区间不代表真实业务分布。

## 工具与安全边界

Python 工具：当前解释器、独立临时目录、环境变量白名单（不继承 API Key）、import/AST 限制、超时和读取输出截断。保留 SymPy 精确表达式，不强转浮点。它仍共享宿主权限，**不是安全沙箱**；数值库可绕过静态限制，文件输出和内存没有操作系统资源配额。对外服务前必须换容器/受控执行服务，当前仅供本地受信实验。

Search：HTTPS MediaWiki API、15 秒单请求超时、结构化错误、共享成功结果缓存。相同查询复用相同页面文本，减少网络漂移；不同查询仍访问实时百科，记录的工具结果才是复核依据。缓存不能保证复现当时所有网络状态。

参考服务商的 [Chat Completions 文档](https://docs.siliconflow.cn/docs/api/chat-completions-post)。每次请求记录 request id、finish reason、模型标识与 token usage；不输出密钥。
