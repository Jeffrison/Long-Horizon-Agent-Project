# 数学精度审计补充

在最终 seed=11 复测仍运行时，数据范围审计发现一题答案为 `2^{25} \cdot 26!`，约 1.35×10^34。
此前预注册 strict-v2 使用浮点数和相对容差；这对大整数不够严格，也可能把接近零的错误数值误判为正确。

修正为 strict-v3：受限 AST + Fraction 精确有理数运算；整数标准答案必须精确相等；非整数数值仅允许相对容差 1e-6，禁止零附近用绝对容差吞掉差异。根号为完全平方数时保持精确，其他支持的数值表达式使用有限浮点近似。仍不使用 eval 或标准答案参与推理。

新增回归：2^53 两侧整数、大整数差一、巨大科学计数近似、精确阶乘、极小非零数、分数与小数、超大指数资源限制。原有 60 个数学标准答案全部可解析并自匹配。

这属于已看到数据后的 **scorer bug fix / protocol amendment**，不会包装成预先盲定的指标。原始 strict-v2 分数、预测与所有轨迹保留；strict-v3 对同一预测离线重判并给出差异明细，不重新采样模型。若两版结果相同，也如实记录；若不同，完整披露差异。

strict-v3 是数值判分器：超出支持语法或非有限值不会判正确，即使字符串相同；一般符号答案需要另行验证。

最终报告分别记录 inference revision 与 scoring revision，不能把更严格判分后的数值变化解释为 Agent 能力变化。
